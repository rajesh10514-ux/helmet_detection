# Helmet Detection

YOLOv8 model jo photo ya webcam me "With Helmet" aur "Without Helmet" detect karta hai.

## Dataset
https://www.kaggle.com/datasets/andrewmvd/helmet-detection
(764 images, 2 classes)

## Chalane ka tarika
1. pip install ultralytics opencv-python
2. best.pt aur run.py ko ek folder me rakho
3. python run.py

Webcam khulega aur helmet detect hoga. Rokne ke liye Ctrl + C dabao.

## Tools
Python, YOLOv8 (Ultralytics), OpenCV, Google Colab
